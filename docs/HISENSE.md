# 海信灵指适配测试版

基于 Nexus-Prime 0.5.5，新增海信 CRF3C65 遥控器 / DRF3U65 USB 接收器的独立设备页。
这是本地适配分支，尚未发布到上游。测试版不接收上游自动更新，避免海信支持被覆盖。

## 使用

1. 退出旧的“海信灵指电脑适配”程序，避免占用接收器。安装本测试版并打开顶部“海信灵指”。
2. 首次使用点击“启用独立按键映射”，允许 Windows 管理员确认。只处理 VID 109B / PID 3834 的 USB 接口 02，使用 Windows 自带 WinUSB；接收器音频接口保持 USB Audio。电脑键盘不参与改键。
3. 为每颗按钮选择键盘/快捷键、语音输入、鼠标左右键、文字、应用程序或不执行。18 颗实体按键及指向时的确认/副键，共 20 个映射项。指向开启和关闭时，确认默认均为触屏点按。按下/松开对应 Windows 触摸接触/抬起，按住移动可拖动。升级旧海信配置时，只将这两项确认映射切换为触屏一次，其余设置保留；以后仍可自由改键。
4. 页面显示“已保存”后设置才已成功落盘。暂停或拔出接收器会释放按键与语音。启用独立映射后，软件需要保持后台运行。退出软件不会自动恢复接收器的 HID 驱动，可在接收器管理中主动恢复。

## 按键学习的边界

已验证的协议包括键盘报告 01 和指向报告 3F；方向键强制使用扩展扫描码，避免右方向变成小键盘 6。
页面允许为所有按钮选择动作，但不代表每颗实体按钮已经发来了可识别的 USB 数据。
对于“待采集”的按键，点击对应“学习”，在 12 秒内只短按该键。指向坐标不会被误学为按键。
若接收器未收到数据，学习超时保留旧设置并提示；原键若仅发红外，需要额外红外接收硬件，不能通过 Windows 按键映射解决。
电源、音量及专用功能键仍需逐颗实机确认。未知厂商报告按短脉冲处理，尚未验证其长按语义；语音建议先绑定已经收到按下/抬起的方向或确认键。

## 语音

所有映射项均可选择“语音输入”。快捷键复用项目的 Codex、微信、豆包、千问预设，也支持自定义与 Hold/Toggle。
Hold 在按下时保持快捷键、松开释放；Toggle 只发送一次快捷键，音频仍随物理按键保持期间传送，与现有项目一致。
声音取自接收器 USB 麦克风，经单声道重采样至 48 kHz 送入现有音频路由和 CABLE 虚拟声卡。
自动选择仅匹配海信 / DRF3U65 / Audio-HID 输入设备；找不到时需手动指定，不会自动改用电脑麦克风。
按键释放、断连、快捷键录入或软件退出时关闭海信采音并释放快捷键；与小米语音进行互斥，避免两路音频混入同一通道。
需要先在原项目首页完成虚拟声卡/音频路由配置，并在目标输入法中选择 CABLE Output。电平和传输帧数只能说明采音/传送，不能证明目标输入法已识音。
遥控器自身是否在非原装语音键按下时开启麦克风仍需硬件验证；映射按钮无法代替未经验证的无线固件录音控制。

## 指向防抖

采用增量指向，启动或重新进入有效指向范围时从当前鼠标位置接续。
“移动灵敏度”控制位移倍率；“微动过滤”抑制细小抖动，同时允许连续慢移累积；“防抖强度”设置自适应平滑时间。
快速移动减轻平滑，屏幕边缘不累积越界位移，反向即可离开边缘。支持 Windows 虚拟桌面范围。
默认 2 倍、18 ms、1.5 px，可自行调整。低延迟直读 USB，禁止把过期坐标放入 UI 消息队列逐条回放。

## 联调中的确定 / AI 手势控制

按最新需求，确定键短按在松开时触摸点按当前位置；长按达到阈值后只移动圆点，不保持触摸。AI 键按下即保持触摸并允许指向移动，松开抬起。默认阈值 350 ms，可在界面调整。
“仅长按确定或按住 AI 时移动”启用后，空闲时舍弃指向位移，圆点停留在当前位置；重新长按从当前坐标接续，不累积未启用期间的移动。遥控器自身指向功能仍需开启。
首次载入此开发版，会将两个确定映射改为“短按触摸 · 长按移动”，AI 改为“按住触摸拖动”，其余映射保留。多个确认通道合并一次短按，拖动中按确认不追加点按；暂停、断连和快捷键录入会取消未完成的短按。
手势状态的三个独立逻辑测试已通过。用户已实机确认四项均符合：空闲不移动、短按确定点按、长按确定仅移动且松开不点击、AI 按住触摸拖动且松开结束。当前开发版保持运行，尚未打安装包。


## 联调中的 AI 短按开关 / 长按滑动

AI 的新映射为“短按开关 · 长按滑动”：短按在松开时切换持续接收坐标的状态，长按达到阈值后保持触摸并滑动。长按松开仅抬起触点，保留原来的持续接收状态。阈值默认 350 ms，可独立于确定键调整。程序重新运行时，AI 短按开关默认关闭。

## 联调中的慢移精细瞄准

开发版按连续指向采样的移动速度调整位移倍率：慢移使用基础灵敏度的 25%，快移平滑恢复至基础倍率；界面可开关，并将慢移倍率调为 10%–75%。速度估计不使用已累积的微动过滤距离，按指向报告实际间隔计算，避免键盘报文频率干扰。
降低倍率仍保留小于一个像素的位移累积；暂停接收后清除速度历史，重新启用从当前指针位置接续。原有防抖与边缘反向行为保留。五项轨迹逻辑测试通过。用户已实测确认“慢移更准，快移也合适”，当前保留默认 25% 慢移倍率和平滑过渡曲线，开发版继续运行，未制作安装包。

## 最新联调：AI 循环三种模式
