# SaloHUb 1.0.0

- 程序更名为 SaloHUb，使用用户提供的图标，版本号从 1.0.0 开始。
- 海信充电状态来自两轮已核对的 USB 插拔报告，只显示充电电源连接状态，不显示未知百分比。
- 按键映射新增命令、按键、宏入口；命令按 Windows、编辑、效率、导航等分类，可搜索分配；按键包含 F1–F24、数字键盘、左右修饰键和媒体键。
- 宏支持不重复、按住重复、触发切换、序列四种方式，可录制键盘、添加鼠标点按、编辑延迟、步骤顺序和宏颜色。宏在输入线程中按时间调度，延迟不阻塞指向接收；停止时释放宏拥有的输入。
- 新增游戏与应用配置管理，按前台 .exe 自动匹配，未单独设置的按键继承桌面默认；提供自动切换开关、固定配置、绑定按键切换配置和左上角切换提示。
- 保留已确认的海信两种 UWB 模式、防抖、精细瞄准、荧光笔和个性化预设、输入法与语音、小米遥控器功能。
- 输入法弹窗与小米统一；映射编辑区位于遥控器下方；托盘仅打开面板与退出。

本版本沿用原应用数据标识与原仓库，作者与维护为 MingDa9916。版本安装包和校验值由本仓库 Releases 发布，私有仓库下载需要登录 GitHub。

新增宏和应用配置功能需在开发版由用户验证，确认后再制作安装包。

构建验证：113 项前端测试、10 项桥接脚本测试通过；海信原生测试 46 项通过、1 项忽略；Rust 全目标检查和 Tauri 调试构建通过。新增宏、应用配置切换及充电状态界面待真实遥控器联调，尚未生成本版正式安装包。
