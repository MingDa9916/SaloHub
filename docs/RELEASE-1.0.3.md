# SaloHUb 1.0.3

- 新增按键映射与宏解析器。可直接编辑指定应用、按键及触发方式的动作，也可编辑完整 JSON 文档，解析后应用。
- 支持导出完整映射、独立宏库和单个宏。导入时会查找本机对应应用。遇到同名程序或未找到应用，可手动重新关联。
- 添加游戏和应用时自动扫描本机，可搜索及按名称或来源排序。宏支持添加启动应用步骤。
- 加强海信串码保护。过滤未知键码，遇到异常键盘报告或长时间未收到键盘状态时释放按键。UWB 保持原始触摸和长按移动两种模式。
- 窗口右侧依次为最小化、最大化或还原、关闭。海信快捷操作新增第五张卡片“遥控器说明书”，可按章节与关键词查询。
- 同步 Nexus Prime v0.5.7 至 v0.5.9 的配置写入保护、重叠按键释放、连接恢复、语音提示音和输入法设置。海信与小米共用提示音设置，提供预设、试听、音量和自定义音频裁剪。

现有用户可在退出托盘中的旧版或预览版后运行 Windows x64 安装程序。现有配置可继续使用。

上游来源：[Nexus Prime 的 v0.5.9 源码](https://github.com/LightyearXizIl/Nexus-Prime/tree/v0.5.9)。
