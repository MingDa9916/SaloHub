# SaloHUb 1.0.2

- 同步上游 Nexus Prime 的标点与多键组合改进，来源提交 [38d49f0](https://github.com/LightyearXizIl/Nexus-Prime/commit/38d49f017e092b392065bfbc71ec1c116a988267)：符号分组、标点单键、Shift 标点、附加键增删、重复按键检查、快捷键文字转下拉继续编辑。
- 小米和海信共用新版组合编辑器，保留海信数字小键盘 Enter、应用独立映射和既有自定义功能。
- 同步 Xiaomi WinUHid 对无法编码的标点组合的回退处理，避免将这类组合误判为设备故障。
- 修复 macOS 风格标题栏的深色选择器，深色主题采用纯黑背景，并保留窗口按钮与关闭到托盘行为。
- 删除导航图标旧的白底容器与缩小图片覆盖样式，修复四周白线；改用内容哈希资源并清除边框、轮廓与阴影。
- 左侧按键编辑框内各功能区均匀分布，保留与右侧底部对齐。

安装后的真实遥控器标点输入及完整回归由用户手动验收。

验证：128 项前端测试、10 项桥接脚本测试、3 项 Xiaomi 原生按键编码测试、Rust 全目标检查及调试构建通过。实际窗口确认深色标题栏与图标无白边，用户确认本轮效果正常。Windows x64 NSIS 安装包已构建。
